03 · Technical Pipeline

텍스트 → 그래프 → API 5단계

1

수집 (Ingest)

6개 매체 RSS·DB 직결·웹훅 → 월 1,300건 원문. 5분 단위 배치 + 실시간.

RSS REST API Webhook DB Direct
2

NER + RE (개체·관계 추출)

인물·기업·금액·날짜·법령·무기체계·신약·판례 자동 인식. Few-shot 프롬프트 + 도메인 사전 결합으로 한국어 도메인 정확도 90~93%.

Gemini 2.5 Pro spaCy KoNLPy Few-shot Domain Dict
3

엔티티 정규화 (Coreference + Linking)

동일인·약어·번역어 통합. "SKT" = "SK텔레콤" = "에스케이텔레콤" = wd:Q485424. Wikidata QID 매핑으로 글로벌 호환.

Coref Wikidata Linking FIBO QID XBRL CIK
4

그래프 적재 + 추론 (Graph Store + Reasoner)

RDF 트리플 + 출처 메타(매체·날짜·기자) → Apache Jena. OWL2 RL 추론기로 자동 도출 사실 생성. Neo4j는 시각화/탐색용 미러.

Apache Jena (RDF) Neo4j (Graph View) OWL2 RL SHACL
5

API 노출 (SPARQL + GraphQL)

SPARQL 1.1 엔드포인트 + GraphQL 미러 + REST shortcut. 인증·과금·rate limit·SLA 99.9%. 응답 평균 240ms.

SPARQL 1.1 GraphQL OAuth2 Stripe Metered CloudFront
04 · Real Use Cases

실 고객이 SPARQL로 묻는 진짜 질문

키워드 검색으로는 절대 답할 수 없는 의사결정용 질의. 컨설턴트 1주일 작업이 1쿼리로.

💼 사모펀드 (PEF) · IR 부서

"K-방산 수출 보유 비상장사 중 IPO 가능성 높은 기업 + 잠재 세무 리스크는?"

① 디펜스투데이 (수출 계약) ② KMNA (IPO 시그널) ③ 월간지방세연구 (관련 판례)
PREFIX ibh: <https://ibh.kr/onto#> SELECT ?company ?contractValue (GROUP_CONCAT(?ipoSignal; separator=", ") AS ?signals) (COUNT(?taxCase) AS ?riskCount) WHERE { # ① 디펜스투데이: K-방산 수출 계약 보유 ?company a ibh:DefenseCorp ; ibh:status ibh:Unlisted ; ibh:hasContract ?c . ?c ibh:source ibh:DefenseToday ; ibh:contractType ibh:DefenseExport ; ibh:value ?contractValue . FILTER(?contractValue > 100000000000) # 1,000억 이상 # ② KMNA: IPO 추진 시그널 OPTIONAL { ?company ibh:mentionedIn ?ipoSignal . ?ipoSignal ibh:source ibh:KMNA ; ibh:topic ibh:IPOFiling } # ③ 월간지방세연구: 관련 세무 판례 OPTIONAL { ?company ibh:relatedTo ?taxCase . ?taxCase a ibh:CourtRuling ; ibh:source ibh:LocalTaxResearch } } GROUP BY ?company ?contractValue ORDER BY DESC(?contractValue) LIMIT 20
→ 응답 240ms 이내 · 12개 후보 기업 + 각 기업의 IPO 시그널 + 평균 2.4건의 잠재 세무 리스크. 출처 매체·날짜·기자 모두 인용 가능. 컨설턴트 1주일 작업 → 1쿼리.
⚖️ 법무법인 · 송무팀

"지방세법 7조 관련 최근 5년 판례 + 그 판례 후 발생한 관련 M&A 거래는?"

① 월간지방세연구 (판례) ② KMNA (M&A 거래) ③ 시계열 추론 (날짜 정렬)
SELECT ?ruling ?rulingDate ?deal ?dealDate ?dealValue WHERE { ?ruling a ibh:CourtRuling ; ibh:cites <https://ibh.kr/law/지방세법§7> ; ibh:rulingDate ?rulingDate . FILTER(?rulingDate > "2021-01-01"^^xsd:date) # 판례 후 발생한 관련 거래 자동 연결 ?deal a ibh:MnaTransaction ; ibh:dealDate ?dealDate ; ibh:dealValue ?dealValue ; ibh:relatedRuling ?ruling . # 추론된 관계 FILTER(?dealDate > ?rulingDate) } ORDER BY ?rulingDate
→ 38건 판례 + 평균 1.6건의 후속 거래 매핑. 변호사가 의뢰인 자문 시 "이 판례 이후 시장이 어떻게 반응했는가"를 즉시 제시 가능. 법률 검토 시간 -73%.
🏛️ 정부 · 과기부 / 기재부 정책 부서

"AI·바이오 신성장 R&D 세제 혜택을 받은 기업의 후속 5G·6G 산업 동향과 M&A는?"

① 월간지방세연구 (세제 적용) ② 바이오타임즈 (바이오 R&D) ③ 애틀러스리서치 (5G·6G 통계) ④ KMNA (후속 M&A)
# 4개 매체 결합 — 정책 효과 추적 (개별 매체로는 불가능) SELECT ?company ?taxCredit ?subsequentMnA ?ictMarketShare WHERE { ?company ibh:receivedTaxBenefit ?credit . ?credit ibh:source ibh:LocalTaxResearch ; ibh:category ibh:RnDTaxCredit ; ibh:amount ?taxCredit . OPTIONAL { ?company ibh:relatedTo ?bioPipeline . ?bioPipeline ibh:source ibh:BioTimes } OPTIONAL { ?company ibh:operatesIn ?ictSegment . ?ictSegment ibh:source ibh:ARG ; ibh:marketShare ?ictMarketShare } OPTIONAL { ?company ibh:involvedIn ?subsequentMnA . ?subsequentMnA ibh:source ibh:KMNA } }

05 · Why We Win

경쟁사가 못 하는 5가지

α

수직 결합 그래프

개별 매체는 자기 도메인만 그래프화 가능. 우리는 6개 매체를 한 그래프에 결합 — 한 사건의 다층 추적이 유일하게 가능합니다.

β

γ

시계열 사실 추적

한 거래의 발생→자문→완료→세제이슈 흐름을 시간순 그래프로. 정태적 검색 엔진에서는 절대 못 만드는 동적 자산.

δ

국제 표준 호환

FIBO·XBRL·Schema.org·Wikidata QID 매핑 → ChatGPT·Claude·Gemini가 별도 변환 없이 직접 인식. 글로벌 LLM 인용 가치 1.5~2배.

ε

15년+ 아카이브

월간지방세연구 2009년부터 = 15년 판례 그래프. 5개 매체 2019년부터 = 7년 산업 거래 그래프. 누적 2.4M 트리플 — 신규 진입자가 따라잡는데 5년+.

★

선명회계 본업 시너지

발행사 신회장(선명회계법인)의 회계·세무 자문 본업 + 그래프 라이선스 결합. 컨설팅 단가 +30~50% — 본업과 자산이 서로 강화.

09 · Limits & Trade-offs

솔직한 한계

NER 정확도 한계

한국어 도메인 NER은 90~93%. 7~10%는 잘못된 추출이 발생.

완화 · 큐레이터 2명 상시 검증 + 사용자 피드백 루프 + 매주 도메인 사전 보강.

저작권 / 데이터 주권

6개 매체 모두 라이선스 동의 필요. 거부 시 해당 채널은 결합 제외.

완화 · (주)비즈뷰 3개는 단일 협상. 신회장 보유 매체이므로 본질적 갈등 없음. 외부 2개는 수익 분배 모델로 협상.

B2B 영업 사이클

1억+ 라이선스 계약은 영업 6~12개월. Tier 4(5억+)는 12~18개월.

완화 · 얼리 어답터 1~2곳 확보 후 사례 마케팅. 첫 사례 후 사이클 6개월 → 2개월.

유지 비용

매월 큐레이션·검증 인력 2~3명 필수. 그래프 DB 호스팅 비용.

완화 · 운영비 월 600만 (Phase 2.5 운영비)에 이미 반영. 매출 7억 대비 비용 비율 10% 미만.

추론 환각 가능성

OWL2 추론기가 잘못된 클래스 정의로 인해 부정확한 사실 도출 가능.

완화 · SHACL shape 제약 + 검증 룰 + 자동 알림. 추론 사실은 명시 사실과 시각적으로 분리(파란색).

경쟁 진입 가능성

대형 미디어가 같은 모델 시도 가능. 단, 매체 수직 결합이 핵심 해자.

완화 · 6개 매체 통합은 흉내내기 어려움. 5년+ 아카이브 + 도메인 전문성 누적이 진입 장벽.
Bottom Line

1.8억 투자 → 3년 +20억 매출 + 영구 자산

그래프 라이선스 신규 매출(+7억/년)은 시작. 진짜 가치는 한국 산업·자본·조세의 단일 인용 그래프를 영구 자산으로 보유한다는 것. 5년 후 이 자산의 시장가는 50억+로 평가될 가능성이 높습니다.
