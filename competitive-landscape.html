Moat Analysis

진입 장벽 — 경쟁사가 따라잡기 어려운 5가지

경쟁사가 우리를 동일하게 복제하려면 200억+ · 5년+가 필요합니다.

16개 한국 매체 인수

(주)비즈뷰 3개 + (주)채널더블유 1개 + 애틀러스리서치 + 한국지방세연구회 = 6개 회사 합병 또는 인수. 예상 비용 80~150억 · 4년+

215년+ 아카이브

월간지방세연구 2009년~ 판례 아카이브 + 5개 매체 2019년~ 콘텐츠 누적 = 누적 2.4M+ 트리플. 시간 자본 — 돈으로 못 산다

3한국 도메인 전문가 6명

바이오·ICT·스타트업·M&A·방산·조세 6개 도메인 모두에 깊은 인력. 각 매체의 발행·편집인이 곧 전문가. 영입 비용 + 신뢰 형성에 3~5년

4회계법인 본업 결합

선명회계법인이라는 본업 + 미디어 그룹 + AI 결합. 글로벌에도 이 정도 결합 모델은 Reuters+Refinitiv 정도가 유일. 한국 시장에는 동급 없음

5AI 인용 라이선스 First Mover

한국 첫 진입자가 OpenAI·Anthropic·Google·Naver·카카오와 5억+ Strategic Tier 계약 체결 시, 5년+ 시장 독점 (한국 매체당 LLM 1사 정도가 표준이 될 가능성)

★6채널 결합 그래프

한 사건이 4~6개 매체에 걸쳐 시간순 추적되는 수직 결합 그래프. 단일 매체로는 흉내 불가능 · 글로벌에도 같은 모델 없음

Worst Case Scenario

가장 위험한 직접 경쟁 시나리오

"조선·중앙·매경 통합 + AI 결합"

시나리오 · 조선미디어 + 매경미디어 + 중앙홀딩스가 통합하여 한국 1티어 종합지 미디어 그룹을 형성하고 AI 라이선스 모델 시작.

위협 요소
  • 한국 1티어 종합지 = 권위 동급
  • 월 발행량 우리의 5배+
  • 독자 규모 우리의 10배+
  • 광고·구독 자본 우위
우리 대응
  • 1티어는 종합지 — 도메인 깊이 부족
  • 우리는 6개 도메인 전문지 = 깊이 1위
  • AI 라이선스 First Mover 선점
  • 본업(선명회계) 시너지 = 종합지 불가능
  • 15년+ 판례 그래프 = 1티어 종합지에도 없음
결론

종합지 1티어와 우리는 서로 다른 시장입니다. 우리는 "도메인 깊이 + B2B + AI 자산"이 핵심 — 종합지의 광고·구독 매스 모델과 직접 경쟁하지 않습니다. 오히려 종합지가 데이터 보강을 위해 우리에게 라이선스를 사는 협력 가능성도.

Bottom Line

동급 직접 경쟁 0 · 영역별 1위만 존재

글로벌 영역별 1위(Bloomberg·PitchBook·Diffbot 등)가 있지만 우리처럼 6개 매체 + AI + 본업 시너지를 동시에 갖춘 모델은 글로벌에도 없습니다. 한국 시장에서는 영역별 1위조차 부재 — 진공 시장에 First Mover로 진입합니다.
