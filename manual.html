1. 시작하기

Insight Bank Hub는 6개 채널을 통합한 발행·검색 플랫폼입니다. 처음 로그인 후 다음 5단계를 따라가세요.

1
로그인

SSO 또는 이메일 OTP로 로그인합니다. 첫 로그인 시 역할(관리자·기자·독자)이 자동 배정됩니다.

2
대시보드 확인

통합 대시보드에서 6채널 KPI·최근 인용·발행 큐를 확인합니다.

3
언어 선택

상단 우측 🌐 언어 선택기에서 8개 언어 중 선택. 설정은 자동 저장되며 다음 방문 시 복원됩니다.

4
역할별 모듈로 이동

기자는 콘텐츠 관리로, 관리자는 운영 콘솔로, 일반 독자는 RAG 챗봇으로 진입합니다.

5
알림 설정

발행·검토·인용 변동 알림을 이메일·Slack·Push로 설정할 수 있습니다.

2. 사용자 역할

플랫폼은 4단계 권한 체계로 운영됩니다.

👑 신회장 / 임원

전체 KPI 열람, 6채널 통합 의사결정, 글로벌 확장 단계 승인. 모든 모듈 읽기/쓰기 권한.

🛠️ 관리자

사용자 관리, 채널 설정, 시스템 설정, RAG 인덱싱 정책, AI 모델 운영.

✍️ 기자 / 편집자

자신의 채널 내 콘텐츠 작성·발행·교열. AI 보조 사용. 인용 점수 확인.

📖 일반 독자

RAG 챗봇 사용, 콘텐츠 검색·읽기, 즐겨찾기. 8개 언어 자유 선택.

3. 기자 가이드

3.1 콘텐츠 작성 워크플로우

  • 초안 작성 — 마크다운 또는 리치 에디터. 템플릿(분석·인터뷰·칼럼·리서치) 선택.
  • AI 보조 — Gemini 기반 교열·요약·태그 추천. 모든 제안은 수락/거부 선택 가능.
  • 메타데이터 — 채널·카테고리·태그·요약문(120자) 입력. JSON-LD는 자동 생성됩니다.
  • 검토 요청 — 검토자 지정. 검토자는 코멘트·수정 제안을 전달.
  • 발행 또는 예약 — 즉시 발행 또는 예약 발행. 다국어 자동 번역 옵션 활성화 가능.

3.2 GEO 점수 향상 팁

  • 제목에 핵심 질문형 키워드 포함 ("2026 R&D 세제 어떻게 바뀌나" 같은 형태)
  • 본문 도입부에 결론 요약 (LLM 인용 시 우선 추출되는 영역)
  • 출처·통계는 인라인 링크로, 외부 1차 자료 인용
  • 200자 단위 청크가 깔끔하게 끊기도록 단락 구분
  • 전문 용어는 첫 등장 시 풀어쓰기 (RAG → 검색 증강 생성)

4. 관리자 가이드

4.1 사용자 / 권한

  • 사용자 초대: 이메일 일괄 초대 + 자동 역할 할당
  • 권한 그룹: 채널별·기능별 세분화 가능
  • SSO 연동: SAML 2.0, OAuth2, OpenID Connect

4.2 RAG 인덱싱 정책

  • 임베딩 모델 변경 시 전체 재인덱스 (예상 4시간)
  • 청크 크기 조정 (기본 512 토큰, 오버랩 64)
  • 채널별 가중치 설정 (예: 전문가 칼럼 +20% 점수)

5. RAG 챗봇 사용법

챗봇 페이지에서 통합 지식 검색을 사용할 수 있습니다.

5.1 효과적인 질문법

  • 구체적 시간: "2026년 세법 개정에서…" (기간을 명시하면 정확도 ↑)
  • 대상 명시: "중소기업 R&D 세액공제…" (대상 범위 좁히기)
  • 출처 요청: "출처 5개 이상 인용해 주세요"
  • 멀티턴: 후속 질문은 이전 컨텍스트를 자동 유지

5.2 채널 필터

좌측 사이드바에서 6개 채널 중 검색 대상을 선택할 수 있습니다. 기본값은 전체 활성화.

8. FAQ

6개 채널의 기존 도메인은 유지되나요?

네. 각 채널의 도메인과 기존 URL 구조는 그대로 유지됩니다. Insight Bank Hub는 새로운 통합 입구이며, 기존 채널은 별도로 운영됩니다. SEO 권한도 유지됩니다.

AI가 잘못된 답변(환각)을 하면 어떻게 되나요?

모든 RAG 응답은 출처 인용이 의무화되어 있습니다. 출처가 없는 답변은 시스템에서 자동 차단되며, 사용자는 응답마다 원문 링크를 확인할 수 있습니다. 환각이 의심될 경우 우측 패널의 '신고' 버튼으로 즉시 신고 가능합니다.

다국어 자동 번역의 정확도는 어떤가요?

Gemini 2.5 Pro 멀티모달 + 도메인 사전 결합으로 회계·세무 분야에서 약 95% 이상의 정확도를 확보합니다. 단, 모든 번역본은 발행 전 검수 단계를 거치며, 관리자가 최종 승인합니다.

외부 LLM이 우리 콘텐츠를 무단 학습하면?

llms.txt + robots.txt로 학습 정책을 명시합니다. 인용은 허용하되 학습은 라이선스 동의 시에만 허용하는 정책 운영이 가능하며, B2B 라이선스 API로 합법적 인용 경로를 제공합니다.

벡터 DB가 다운되면 챗봇은 어떻게 되나요?

이중화된 벡터 DB와 캐시 레이어를 운영합니다. 1차 장애 시 자동 페일오버, 2차 장애 시에도 직전 24시간 캐시로 답변 가능. SLA는 99.9% 가용성입니다.

아랍어를 선택했을 때 차트는 어떻게 보이나요?

페이지 레이아웃과 텍스트는 RTL(우→좌)로 전환되지만, 숫자·차트·SVG 다이어그램은 가독성을 위해 LTR을 유지합니다. 캡션과 범례는 아랍어로 자동 번역됩니다.

모바일에서 모든 기능을 사용할 수 있나요?

네. 모바일 우선(Mobile-First) 설계로 PWA 지원. 챗봇·콘텐츠 관리·대시보드·언어 전환 등 모든 기능이 모바일에 최적화되어 있습니다. iOS/Android 홈 화면 추가도 가능합니다.
