1. 시작하기

Insight Bank Hub는 6개 채널을 통합한 발행·검색 플랫폼입니다. 처음 로그인 후 다음 5단계를 따라가세요.

1
로그인

SSO 또는 이메일 OTP로 로그인합니다. 첫 로그인 시 역할(관리자·기자·독자)이 자동 배정됩니다.

2
대시보드 확인

통합 대시보드에서 6채널 KPI·최근 인용·발행 큐를 확인합니다.

3
언어 선택

상단 우측 🌐 언어 선택기에서 8개 언어 중 선택. 설정은 자동 저장되며 다음 방문 시 복원됩니다.

4
역할별 모듈로 이동

기자는 콘텐츠 관리로, 관리자는 운영 콘솔로, 일반 독자는 RAG 챗봇으로 진입합니다.

5
알림 설정

발행·검토·인용 변동 알림을 이메일·Slack·Push로 설정할 수 있습니다.

2. 플랫폼 14개 모듈

Insight Bank Hub는 14개 독립 페이지로 구성되며, 단일 인증·단일 데이터 위에서 동작합니다.

2.1 핵심 자료 (제안·영업)

  • 개요 — 플랫폼 비전 + 8개 모듈 진입점 + 6개 매체 + 글로벌 8개 언어
  • 계약 제안서 — 선명회계법인 12개월 도입 로드맵 (Phase 1~4) · 가격 (현재 000 마스킹)
  • 6개 채널 — 바이오타임즈·ARG·스타트업투데이·KMNA·디펜스투데이·월간지방세연구 상세 + 한국 1위 표기
  • 상품·서비스 — 8개 카테고리 36종 + B2B 1-pager 인쇄 (Ctrl+P)
  • 수익 모델 — 9개 Stream + 글로벌 단가 비교 + 36종 매핑 + Y3 88억
  • 경쟁 환경 — 8영역 40+ 경쟁사 (Bloomberg·PitchBook·Diffbot 등) + Moat + 위협

2.2 기술 / 차별화 (의사결정자용)

  • 온톨로지 — Phase 2.5 도메인 그래프 + FIBO/XBRL 호환 + 6채널 결합 추론
  • 그래프 라이선스 — Stream 09 SPARQL API B2B 영업 자료 + 4티어 가격
  • 시스템 구조도 — 4-Layer SVG 아키텍처 + 기술 스택

2.3 운영 데모 (실제 사용)

  • 대시보드 — 6채널 통합 KPI · AI 인용 추이 · 히트맵
  • 콘텐츠 관리 — 6채널 발행 큐 + GEO 점수 + AI 보조
  • 지식베이스 — RAG 벡터 인덱스 + 토픽 클러스터 + AI 인용 점수
  • RAG 챗봇 — Gemini 기반 통합 검색 + 출처 인용 + 멀티턴
  • 운영 매뉴얼 — 본 문서
고객 유형별 권장 진입 경로
  • 신회장/임원 → 개요 → 제안서 → 경쟁 환경 → 수익 모델
  • 기술 임원/CTO → 시스템 구조도 → 온톨로지 → 그래프 라이선스 → 지식베이스
  • B2B 영업팀 → 상품·서비스 → 그래프 라이선스 → 경쟁 환경 (인쇄)
  • 투자자/IR → 수익 모델 → 경쟁 환경 → 제안서
  • 기자/편집자 → 콘텐츠 관리 → 매뉴얼 4. 기자 가이드 → 챗봇
  • 독자 → 챗봇 → 6개 채널 → 지식베이스

3. 사용자 역할

플랫폼은 4단계 권한 체계로 운영됩니다.

👑 신회장 / 임원

전체 KPI 열람, 6채널 통합 의사결정, 글로벌 확장 단계 승인. 모든 모듈 읽기/쓰기 권한.

🛠️ 관리자

사용자 관리, 채널 설정, 시스템 설정, RAG 인덱싱 정책, AI 모델 운영.

✍️ 기자 / 편집자

자신의 채널 내 콘텐츠 작성·발행·교열. AI 보조 사용. 인용 점수 확인.

📖 일반 독자

RAG 챗봇 사용, 콘텐츠 검색·읽기, 즐겨찾기. 8개 언어 자유 선택.

4. 기자 가이드

3.1 콘텐츠 작성 워크플로우

  • 초안 작성 — 마크다운 또는 리치 에디터. 템플릿(분석·인터뷰·칼럼·리서치) 선택.
  • AI 보조 — Gemini 기반 교열·요약·태그 추천. 모든 제안은 수락/거부 선택 가능.
  • 메타데이터 — 채널·카테고리·태그·요약문(120자) 입력. JSON-LD는 자동 생성됩니다.
  • 검토 요청 — 검토자 지정. 검토자는 코멘트·수정 제안을 전달.
  • 발행 또는 예약 — 즉시 발행 또는 예약 발행. 다국어 자동 번역 옵션 활성화 가능.

3.2 GEO 점수 향상 팁

  • 제목에 핵심 질문형 키워드 포함 ("2026 R&D 세제 어떻게 바뀌나" 같은 형태)
  • 본문 도입부에 결론 요약 (LLM 인용 시 우선 추출되는 영역)
  • 출처·통계는 인라인 링크로, 외부 1차 자료 인용
  • 200자 단위 청크가 깔끔하게 끊기도록 단락 구분
  • 전문 용어는 첫 등장 시 풀어쓰기 (RAG → 검색 증강 생성)

5. 관리자 가이드

6. RAG 챗봇 사용법

챗봇 페이지에서 통합 지식 검색을 사용할 수 있습니다.

5.1 효과적인 질문법

  • 구체적 시간: "2026년 세법 개정에서…" (기간을 명시하면 정확도 ↑)
  • 대상 명시: "중소기업 R&D 세액공제…" (대상 범위 좁히기)
  • 출처 요청: "출처 5개 이상 인용해 주세요"
  • 멀티턴: 후속 질문은 이전 컨텍스트를 자동 유지

5.2 채널 필터

좌측 사이드바에서 6개 채널 중 검색 대상을 선택할 수 있습니다. 기본값은 전체 활성화.

7. 그래프 라이선스 (B2B)

Stream 09 — SPARQL 그래프 라이선스는 6개 매체 결합 RDF 그래프를 B2B 고객(법무법인·PEF·IB·정부·LLM)에게 라이선싱하는 차별화 영역입니다.

7.1 4티어 가격

  • Tier 1 · Read-only Query — 연 3,600만 (월 100K 쿼리, 출처 인용)
  • Tier 2 · Pro — 연 9,600만 (OWL2 추론 + GraphQL + 전담 매니저)
  • Tier 3 · Enterprise — 연 2.8억 (8개 언어 + 무제한 + SLA 99.9%)
  • Tier 4 · Strategic — 연 5억+ (LLM 학습 라이선스 + 전체 트리플 덤프 + 공동 모델 개발)

7.2 SPARQL 엔드포인트 사용법

POST /sparql
Authorization: Bearer <your-api-key>
Content-Type: application/sparql-query

PREFIX ibh: <https://ibh.kr/onto#>
SELECT ?company ?contractValue
WHERE {
  ?company a ibh:Corporation ;
           ibh:hasContract ?c .
  ?c ibh:contractType ibh:DefenseExport ;
     ibh:value ?contractValue .
}
LIMIT 20

7.3 영업 자료

  • graph-license.html — 전체 B2B 영업 자료 (Diffbot 비교 + 4티어 + 14개월 일정)
  • ontology.html — 기술 상세 (NER/RE 파이프라인, 도메인 트리, 추론 룰)
  • products.html#06 — 상품 카드 + 가격

7.4 차별화 메시지 (영업 한 줄)

"Diffbot은 영문 웹 그래프, 우리는 한국 산업·자본·조세 큐레이션 그래프 — 한 사건이 4~6개 매체에 걸쳐 시간순 추적되는 수직 결합. 단일 매체로는 흉내 불가."

8. B2B 영업 가이드

36종 상품을 개별 판매하지 않고 고객 유형별 6종 패키지로 묶음 영업하여 사이클 6개월 → 3개월로 단축.

8.1 고객 유형별 패키지 6종

  • 법무법인 패키지 (연 9,600만): 지방세 판례 + M&A DB + 그래프 라이선스 Tier 1
    → 김앤장·광장·세종·율촌·화우·태평양
  • 사모펀드/IB 패키지 (연 2.5억): M&A + VC 펀딩 + K-방산 + 그래프 Pro + 임원 브리핑
    → MBK·IMM·한앤컴퍼니·미래에셋·NH·삼성증권 IB
  • 대기업 IR 패키지 (연 3.6억): Enterprise RAG + 맞춤 분석 + 임원 브리핑 + 기업 구독
    → 삼성·SK·LG·현대차 IR·신사업
  • 바이오 IR 패키지 (연 1.8억): 바이오 임상 DB + M&A + 임원 브리핑 + 맞춤 분석
    → 셀트리온·삼성바이오·SK바이오팜·한미·녹십자
  • 정부·공공 패키지 (연 8억+): 그래프 Enterprise + 정책 자문 + 글로벌 인덱스
    → 기재부·과기부·산업부·국민연금·KIC
  • ★ LLM 회사 패키지 (연 10억+): LLM 학습 라이선스 + 다국어 8개 + 그래프 Strategic
    → OpenAI·Anthropic·Google·Naver·카카오

8.2 1-pager 인쇄 (영업 미팅용)

products.html에서 Ctrl/⌘ + P 누르면 A4 형태의 영업 자료가 즉시 출력됩니다. @media print 최적화 — 헤더/푸터 자동 숨김.

8.3 영업 사이클

  • Tier 1~2 (연 1억 이하): 영업 사이클 1~2개월
  • Tier 3 · Enterprise (연 2~5억): 영업 사이클 4~6개월
  • Tier 4 · Strategic (연 5억+): 영업 사이클 12~18개월 (의사결정자 직접 접촉 필요)

8.4 First Reference 확보 전략

첫 사례 1~2곳 확보가 후속 영업의 결정적 무기. 우선 타깃:

  • 법무법인 1곳 — 김앤장 또는 광장 (지방세 + M&A 결합)
  • PEF 1곳 — MBK 또는 IMM (M&A + VC 결합)
  • LLM 1곳 ★ — Naver 또는 카카오 (한국 LLM 우선, 그 후 글로벌 진출)

9. 선명회계법인 본업 시너지

36종 중 8종이 회계·세무·M&A 본업과 직접 시너지. 본업 단가 +30~50% 정당화.

9.1 본업 결합 8종 상품

  • #07 M&A 거래 DB + 회계법인 M&A 자문 → 거래 단가 +50%
  • #12 지방세 판례 DB + 세무 자문 → 일상 자문 도구
  • #19 도메인 분기 리포트 (조세) + 본업 컨설팅
  • #20 맞춤 시장 분석 + M&A 실사
  • #27 M&A 자문 보조 — 데이터 백본 + 본업 결합 핵심
  • #28 정부·공공 정책 자문 — 그래프 + 본업 정량 분석
  • #30 지방세 공무원 보수교육 — 한국지방세연구회 활용
  • #31 회계사·세무사 CPE + 본업 강사진

9.2 영업 통합 워크플로우

  1. 선명회계 본업 고객사 (200+) → IBH 데이터 라이선스 교차 영업
  2. IBH 그래프 라이선스 고객 (법무법인·PEF) → 본업 자문 의뢰 유도
  3. 월간지방세연구 발행 → 신규 회계·세무 클라이언트 발굴 채널
  4. 임원 분기 브리핑 (#29) → 본업 자문 계약 갱신·확장

9.3 통합 KPI

  • 본업 → IBH 교차 매출: 연 1.2억 (B2B 패키지 기준)
  • IBH → 본업 추천 매출: 연 3.6억 (M&A 자문 + 컨설팅)
  • 총 시너지 매출: 연 4.8억+

6.3 RTL (아랍어) 지원

  • 아랍어 선택 시 페이지 전체가 우→좌 레이아웃으로 자동 전환
  • 숫자·차트·SVG는 LTR 유지 (가독성)
  • 사진 캡션·표는 RTL 정렬

6.4 언어별 GEO 최적화

  • EN · ChatGPT, Claude, Perplexity 영어 인덱스
  • ZH · Qwen, DeepSeek, Doubao 중국어 인덱스
  • JA · Sakana AI, ELYZA, 일본어 ChatGPT
  • EU 언어 · Mistral, Gemini 다국어, Aleph Alpha

12. FAQ

6개 채널의 기존 도메인은 유지되나요?

네. 각 채널의 도메인과 기존 URL 구조는 그대로 유지됩니다. Insight Bank Hub는 새로운 통합 입구이며, 기존 채널은 별도로 운영됩니다. SEO 권한도 유지됩니다.

AI가 잘못된 답변(환각)을 하면 어떻게 되나요?

모든 RAG 응답은 출처 인용이 의무화되어 있습니다. 출처가 없는 답변은 시스템에서 자동 차단되며, 사용자는 응답마다 원문 링크를 확인할 수 있습니다. 환각이 의심될 경우 우측 패널의 '신고' 버튼으로 즉시 신고 가능합니다.

다국어 자동 번역의 정확도는 어떤가요?

Gemini 2.5 Pro 멀티모달 + 도메인 사전 결합으로 회계·세무 분야에서 약 95% 이상의 정확도를 확보합니다. 단, 모든 번역본은 발행 전 검수 단계를 거치며, 관리자가 최종 승인합니다.

외부 LLM이 우리 콘텐츠를 무단 학습하면?

llms.txt + robots.txt로 학습 정책을 명시합니다. 인용은 허용하되 학습은 라이선스 동의 시에만 허용하는 정책 운영이 가능하며, B2B 라이선스 API로 합법적 인용 경로를 제공합니다.

벡터 DB가 다운되면 챗봇은 어떻게 되나요?

이중화된 벡터 DB와 캐시 레이어를 운영합니다. 1차 장애 시 자동 페일오버, 2차 장애 시에도 직전 24시간 캐시로 답변 가능. SLA는 99.9% 가용성입니다.

아랍어를 선택했을 때 차트는 어떻게 보이나요?

페이지 레이아웃과 텍스트는 RTL(우→좌)로 전환되지만, 숫자·차트·SVG 다이어그램은 가독성을 위해 LTR을 유지합니다. 캡션과 범례는 아랍어로 자동 번역됩니다.

모바일에서 모든 기능을 사용할 수 있나요?

네. 모바일 우선(Mobile-First) 설계로 PWA 지원. 챗봇·콘텐츠 관리·대시보드·언어 전환 등 모든 기능이 모바일에 최적화되어 있습니다. iOS/Android 홈 화면 추가도 가능합니다.
