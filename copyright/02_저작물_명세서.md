# 저작물 명세서 — Insight Bank Hub (편집저작물)

> 본 명세서는 한국저작권위원회 편집저작물 등록 시 첨부하는 저작물 상세 설명서다.
> 편집저작물 관점에서 **"저작자가 무엇을 어떻게 선택·배열·구성했는가"**를 기술한다.
> 본 등록은 **소스코드의 창작성이 아니라 편집의 창작성**을 보호 대상으로 한다 (03 §0 참조).
> 2026-05-04 기준 (베이스 `4cc5d17`).

## 1. 프로젝트 개요

### 1.1 편집 목적
한국 산업·자본·조세 분야의 분산된 6개 인터넷 매체와 그 주변 콘텐츠를 **AI 시대(ChatGPT · Claude · Gemini · Perplexity)에 인용 가능한 단일 출처(GEO-AIO 싱크탱크)로 자산화**할 수 있도록, 매체 정보·기능 모듈·상품 카탈로그·수익 모델·시스템 아키텍처·다국어 매트릭스·통합 인사이트 사례·사업계획서를 하나의 디지털 플랫폼 위에 **선택·배열·구성**한 편집저작물.

### 1.2 편집 기획 의도 (저작자의 단독 의사결정)
- 단순 6개 매체의 묶음(나열)이 아닌, **GEO-AIO 관점의 큐레이션**
- 의사결정자(임원/CTO/B2B 영업/투자자/기자/독자) 6 페르소나별 진입 경로 설계
- 4-Layer 아키텍처 기반의 모듈식 정보 위계
- **6채널 결합으로만 가능한 통합 인사이트**(사례 보기)를 살아있는 증명으로 제시
- **사업계획서**(6 핵심 섹션 + 200단어 해설)로 IR/투자자 의사결정 지원
- 한국 미디어 산업 전체로 확장 가능한 미디어 중립 아키텍처

### 1.3 표현 매체 (편집 결과물의 형태)
- 정적 웹 사이트 (HTML5 + CSS3 + JavaScript) + Serverless RSS API
- White Premium 테마 + Heritage Gold + Royal Purple 액센트 + 글래스 모피즘
- KoPubWorld Dotum (한국출판인회의 무료 한글 폰트) + Pretendard 폴백
- 모바일 우선 + RTL(아랍어) 부분 지원
- 영문 약어 자동 확장기 (첫 등장 시 `(English · 한글)` 표기)

> ※ 위 표현 매체는 편집의 그릇일 뿐, 본 등록의 보호 대상은 그 위에 담긴 **편집의 창작성**이다.
