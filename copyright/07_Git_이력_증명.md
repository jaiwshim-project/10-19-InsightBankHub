## 5. 검증 방법 (한국저작권위원회 보정 요청 시)

### 5.1 원격 저장소 직접 확인
```
https://github.com/jaiwshim-project/10-19-InsightBankHub
→ Insights → Contributors (단독 기여자 확인)
→ Commits (시간순 이력 확인)
```

### 5.2 로컬에서 재현
```bash
git log --pretty=format:"%h|%ad|%an|%s" --date=iso-strict --reverse
git rev-list --count HEAD
git shortlog -sne
```

### 5.3 Git 데이터 무결성
```bash
git fsck --full
git rev-parse HEAD
```
→ Git의 SHA-1 해시는 변조 시 즉시 감지됨. 위 4개 해시는 변조 불가능한 창작 증명.
