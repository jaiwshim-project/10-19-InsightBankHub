## 6. 제출 형식

### 권장: PDF 변환
1. 위 Tier 1~2 파일을 한국저작권위원회 가이드에 따라 PDF 변환
2. 파일당 페이지 번호 + 헤더에 저작물명 부착
3. 표지 추가 (저작자명·저작물명·등록 카테고리)

### PowerShell 자동 변환 예시
```powershell
# 모든 HTML을 PDF로 일괄 변환 (Edge Headless)
$files = Get-ChildItem "C:\01 Claude-Code\10-19 Insight Bank Hub (인사이트 뱅크 허브)\*.html"
foreach ($f in $files) {
  $pdf = $f.FullName -replace '\.html$', '.pdf'
  & "msedge.exe" --headless --disable-gpu --print-to-pdf="$pdf" "file:///$($f.FullName)"
}
```

### 대안: ZIP 제출
- 전체 디렉토리(node_modules·.git 제외)를 ZIP으로 압축
- 한국저작권위원회 온라인 등록 시 ZIP 업로드 옵션 사용
