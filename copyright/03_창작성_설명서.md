> 2026-05-04 기준 (베이스 `4cc5d17`).

## 0. 본 등록의 본질 — 편집의 창작성, 코드의 창작성이 아니다

### 0.1 저작권법 제6조 (편집저작물)
> ① **편집저작물**은 그 소재의 **선택·배열 또는 구성**에 창작성이 있는 것을 말한다.
> ② 편집저작물은 독자적인 저작물로서 보호된다.
> ③ 편집저작물의 보호는 그 편집저작물의 구성부분이 되는 소재의 저작권 그 밖에 이 법에 따라 보호되는 권리에 영향을 미치지 아니한다.

### 0.2 본 등록의 보호 범위 (명확화)

| 보호 대상 | 본 등록 |
|---------|---------|
| 인간 저작자가 의도적으로 결정한 **소재의 선택·배열·구성** | ✅ 보호 |
| 코드의 개별 줄·구문·알고리즘 자체 | ❌ 본 등록 대상 아님 (컴퓨터프로그램저작물이 아니므로) |
| AI 도구가 생성한 코드 표현 | ❌ 본 등록 대상 아님 |
| 6개 매체의 콘텐츠 자체 | ❌ 각 매체사 권리 |
| 외부 폰트·라이브러리·LLM | ❌ 별도 권리자 |

### 0.3 한국저작권위원회의 AI 생성물 가이드라인 (2024-12 기준)에 대한 입장
- 위원회는 "AI가 생성한 결과물" 자체에는 저작권이 인정되지 않는다는 입장이다.
- 그러나 **편집저작물(제6조)**은 그 본질이 "소재의 선택·배열·구성"에 있으며, 이는 **인간 저작자의 의사결정**이 보호 대상이다.
- 본 저작물에서 **편집 의사결정의 100%는 저작자(심재우)의 단독 행위**이며, AI 도구는 그 의사결정에 따른 코드·텍스트의 표현 수단으로만 활용되었다.
- 따라서 본 등록은 위원회의 AI 가이드라인과 충돌하지 않는다.

→ 본 등록은 ① 소재 선택, ② 소재 배열, ③ 소재 구성의 **세 차원 모두**에서 인간 저작자의 창작적 의사결정을 입증한다.

## 1. 소재 선택의 창작성

### 1.1 6개 매체 선별의 큐레이션 가치
한국에는 수백 개 인터넷 매체가 존재한다. 이 중 다음 6개를 선별한 것은 **GEO-AIO(Generative Engine Optimization + AI Answer Optimization) 관점의 독자적 큐레이션**이며, 이 선별 의사결정은 **저작자의 단독 판단**이다 (AI 도구의 추천이 아님).

| 선별 매체 | 선별 근거 (저작자의 편집 의도) |
|----------|--------------------|
| 바이오타임즈 | 바이오·신약 전문 — LLM이 임상 정보를 인용할 때 가장 자주 호출되는 도메인 |
| ARG | 텔레콤·IT·방송 리서치 — 한국 ICT 산업의 정량 분석 자산 |
| 스타트업투데이 | VC·투자 — M&A의 선행 지표 (Pre-IPO 기업 정보) |
| 한국M&A경제신문 | M&A·IPO·자본시장 — 한국 자본시장 권위 매체 |
| 디펜스투데이 | K-방산 — 글로벌 LLM이 한국 방산을 다룰 때 결정적 1차 출처 |
| 월간지방세연구 | 지방세·조세 — 15년+ 아카이브, 한국 유일의 지방세 학술 매체 |

→ 이 6개의 조합은 **"산업 + 자본 + 조세"라는 3축 결합**을 만든다. 이 3축을 단일 매체 안에 결합한 사례는 한국에 없으며, 본 편집은 이를 의도적으로 선별·결합했다.

### 1.2 36종 상품의 8 카테고리 분류 (큐레이션)
일반적인 미디어 사업이 광고/구독에 집중하는 데 반해, 본 편집은 저작자의 의사결정으로 **8 카테고리 36종**으로 상품 우주를 확장했다.
- AI 인용 라이선스 (Stream 07) — LLM 학습·인용에 대한 합법적 라이선스 모델
- 그래프 라이선스 (Stream 09) — SPARQL 엔드포인트를 4티어 가격으로 분할 (Royal Purple 토큰)
- 본업 결합 8종 — 회계·세무·M&A 본업과 시너지를 갖는 상품 묶음

### 1.3 6 페르소나별 진입 경로 설계
16개 모듈을 누가 어떻게 볼 것인지를 의사결정자 6 페르소나로 분해해 진입 경로를 큐레이션했다.

| 페르소나 | 권장 경로 |
|---------|----------|
| 신회장/임원 | 개요 → 제안서 → 사업계획서 → 경쟁 환경 → 수익 모델 |
| 기술 임원/CTO | 시스템 구조도 → 온톨로지 → 사례 보기(3D 그래프) → 그래프 라이선스 |
| B2B 영업팀 | 상품·서비스 → 그래프 라이선스 → 경쟁 환경 (인쇄) |
| 투자자/IR | 사업계획서 → 수익 모델 → 경쟁 환경 → 제안서 |
| 기자/편집자 | 콘텐츠 관리 → 매뉴얼 → 챗봇 |
| 일반 독자 | 챗봇 → 6개 채널 → 사례 보기 → 지식베이스 |

→ 페르소나-경로 매트릭스는 저작자의 단독 의사결정의 결과물이다.

### 1.4 사업계획서 6 핵심 섹션 선택
일반 템플릿이 아니라, 저작자의 판단으로 **GEO-AIO 사업의 본질에 맞춘 6 섹션**을 선별했다: 시장 → BM → 재무 → 로드맵 → 리스크 → 자금. 각 섹션 200단어 해설은 저작자가 직접 집필한 어문 표현이다.

### 1.5 사례 보기 시나리오 선택
"K-방산 무인화 가속 + IPO 후보 5종 + R&D 세제·M&A 시그널"이라는 **단일 매체로는 만들 수 없는 통합 인사이트** 시나리오를 저작자가 직접 큐레이션했다. 6채널 컨트리뷰션을 명시적으로 매핑한 점에서 편집 창작성 입증력이 높다.

## 2. 배열·구성의 창작성

### 2.1 5 그룹 메뉴 위계 (저작자의 의사결정)
초기 14개 모듈을 단순 나열한 상태에서, 저작자는 의도적으로 **5 그룹(개요 · 제안 · 기술 · 데모 · 사례 보기)**으로 위계화했다 (커밋 `770f6c2`).

- "개요"는 진입점 — 1순위
- "제안"은 영업 자료 (사업계획서 포함) — B2B/IR 의사결정자용 2순위
- "기술"은 차별화 자료 (사례 보기 포함) — 기술 평가자용 3순위
- "데모"는 운영 화면 — 실사용 검증용 4순위
- "사례 보기"는 통합 인사이트 단독 노출 — 차별성 증명 5순위

이 위계는 헤더와 푸터에 일관 적용되어 사이트 전체의 정보 흐름을 결정한다.

## 3. 디자인 편집의 창작성

> ※ 디자인 토큰의 구체적 색상값은 표준 색상값일 수 있으나, **어떤 토큰을 어떤 카테고리에 어떻게 매핑할지**는 저작자의 편집 의사결정이다.

### 3.1 White Premium 테마 + 4색 액센트 체계
다크 → 화이트 프리미엄 테마로의 전환(커밋 `9d1e88e`)은 저작자가 가독성·권위 양립을 위해 결단한 편집 결정이다.

- **White Premium 베이스** (`#fafaf6` ~ `#fbf6ec`의 5단계 elevation)
- **Heritage Gold 액센트** (`#fbf6ec` ~ `#6e4a25`의 6단계, 화이트 배경 가독성 최적화)
- **Insight Blue 액센트** (`#2c6fc2` ~ `#0e264a`의 4단계 deep tone)
- **Royal Purple 액센트** (`#7e22ce` ~ `#4a1380`의 3단계, 신규) — Phase 2.5 · Stream 09 · 월간지방세연구 단독 시각 코드

이 4색 액센트는 "전통적 권위(Gold) + 디지털 미래(Blue) + 학술 권위(Purple) + 인쇄 헤리티지(White)"의 시각적 응축이며, 저작자의 의도적 매핑이다.

### 3.2 Type Scale 재계산 (가독성 +1px)
저작자가 모든 페이지의 가독성과 위계 균형을 검토한 후 폰트 크기를 일괄 +1px 증가시켰다(커밋 `9a9a883`). 단순 일괄 변경이 아니라 모든 디바이스에서 타이포그래피 위계를 유지하기 위한 편집 결정.

### 3.3 텍스트 대비 토큰 (WCAG 명도비)
화이트 배경(`#fafaf6`) 기준으로 명도비를 계산해 4단계 텍스트 토큰을 설계:
- `--text-primary` 16.0:1 (AAA · 본문 강조)
- `--text-secondary` 11.5:1 (AAA · 본문)
- `--text-muted` 5.8:1 (AA · 보조 라벨)
- `--text-faint` 3.2:1 (Large text only)

→ 명도비 기반 4단계 위계는 저작자의 디자인 편집 결정.

### 3.4 KoPubWorld Dotum 폰트 채택과 폴백 설계
저작자가 무료 한글 폰트 중 출판 환경 가독성을 가진 KoPubWorld Dotum을 의도적으로 선별했다. **로컬 → jsDelivr CDN → 시스템 sans-serif** 3순위 폴백 구성은 저작자가 운영 안정성을 위해 결정한 편집의 결과.

### 3.5 디자인 토큰 카테고리 매핑

| 카테고리 | 토큰 수 | 편집 의도 |
|---------|--------|----------|
| Background (White Premium) | 5 | 헤리티지 인쇄 톤 |
| Heritage Gold (deep tone) | 6 | 자산 위상 |
| Insight Blue (deep tone) | 4 | AI/디지털 |
| Royal Purple (신규) | 3 | 학술/그래프 단독 |
| Semantic | 4 | 화이트 bg 가독성 |
| Text (4단계 명도비) | 5 | WCAG 위계 |
| Border / Glass / Shadow / Radius / Spacing / Type / Layout / Easing | 47 | 통합 디자인 시스템 |
| **합계** | **74+** | |

→ 토큰의 색상값 자체는 표준 표현일 수 있으나, **어떤 토큰을 만들지 / 어떤 카테고리에 매핑할지**는 저작자의 단독 의사결정.

## 4. 다국어 편집의 창작성

### 4.1 8개 언어 GEO 매트릭스 (LLM 매핑)
일반적인 i18n이 "텍스트 번역"에 그치는 데 반해, 저작자는 **각 언어를 타깃 LLM에 매핑**한 GEO 매트릭스를 설계했다.

| 언어 | 타깃 LLM 매핑 (저작자의 큐레이션) |
|------|-------------------------|
| EN | ChatGPT · Claude · Perplexity (영어 인덱스) |
| ZH | Qwen · DeepSeek · Doubao (중국어 인덱스) |
| JA | Sakana AI · ELYZA · 일본어 ChatGPT |
| ES/FR/DE | Mistral · Gemini 다국어 · Aleph Alpha (EU LLM) |
| AR | Falcon · Jais (아랍어 LLM, RTL 부분 적용) |

→ "어떤 언어를 어떤 LLM에 노출시킬 것인가"라는 매핑 자체가 편집 창작성.

### 4.2 영문 약어 사전 큐레이션
저작자가 직접 큐레이션한 약어 사전(NER · RE · FIBO · XBRL · RAG · GEO 등)과 **첫 등장 시 풀이 부착** 규칙은 저작자의 편집 의사결정이다.

- NER → `(Named Entity Recognition · 개체명 인식)`
- FIBO → `(Financial Industry Business Ontology · 금융 산업 비즈니스 온톨로지)`
- 기타

> ※ 약어 부착의 알고리즘 표현(코드)은 본 등록 대상이 아니다. 본 등록은 **약어 사전의 큐레이션과 부착 규칙의 편집 의도**를 보호한다.

### 4.3 RTL(아랍어) 부분 적용 규칙
- 페이지 레이아웃·텍스트는 RTL
- 숫자·차트·SVG는 가독성을 위해 LTR 유지
- 캡션/범례는 아랍어 자동 번역

→ "가독성을 해치지 않는 부분 RTL" 규칙 자체가 저작자의 편집 결정.

## 5. 기존 저작물과의 차별점

| 비교 대상 | 차이 |
|----------|------|
| 단순 매체 모음 사이트 | 매체 나열 vs **6 페르소나 진입 경로 + 4-Layer 아키텍처 + 6채널 결합 사례** |
| Diffbot, GDELT (글로벌 그래프) | 영문 일반 웹 vs **한국 산업·자본·조세 수직 결합 + 3D 온톨로지 시각화** |
| Bloomberg Terminal | 데이터 단말 vs **AI 인용 라이선스 + GEO-AIO 자산화** |
| 일반 i18n 사이트 | 8개 언어 번역 vs **언어별 LLM 타깃 매핑 + 약어 사전 큐레이션** |
