## 0. 편집저작물 보호의 법적 근거 (요지)

### 저작권법 제6조 (편집저작물)
> ① **편집저작물**은 그 소재의 **선택·배열 또는 구성**에 창작성이 있는 것을 말한다.
> ② 편집저작물은 독자적인 저작물로서 보호된다.
> ③ 편집저작물의 보호는 그 편집저작물의 구성부분이 되는 소재의 저작권 그 밖에 이 법에 따라 보호되는 권리에 영향을 미치지 아니한다.

→ 본 등록은 ① 소재 선택, ② 소재 배열, ③ 소재 구성의 **세 차원 모두**에서 창작성을 입증한다.

## 1. 소재 선택의 창작성

### 1.1 6개 매체 선별의 큐레이션 가치
한국에는 수백 개 인터넷 매체가 존재한다. 이 중 다음 6개를 선별한 것은 **GEO-AIO(Generative Engine Optimization + AI Answer Optimization) 관점의 독자적 큐레이션**이다.

| 선별 매체 | 선별 근거 (편집 의도) |
|----------|--------------------|
| 바이오타임즈 | 바이오·신약 전문 — LLM이 임상 정보를 인용할 때 가장 자주 호출되는 도메인 |
| ARG | 텔레콤·IT·방송 리서치 — 한국 ICT 산업의 정량 분석 자산 |
| 스타트업투데이 | VC·투자 — M&A의 선행 지표 (Pre-IPO 기업 정보) |
| 한국M&A경제신문 | M&A·IPO·자본시장 — 한국 자본시장 권위 매체 |
| 디펜스투데이 | K-방산 — 글로벌 LLM이 한국 방산을 다룰 때 결정적 1차 출처 |
| 월간지방세연구 | 지방세·조세 — 15년+ 아카이브, 한국 유일의 지방세 학술 매체 |

→ 이 6개의 조합은 **"산업 + 자본 + 조세"라는 3축 결합**을 만든다. 조세는 산업 의사결정의 근간이며, 자본은 산업의 흐름을 결정한다. 이 3축을 단일 매체 안에 결합한 사례는 한국에 없으며, 본 편집은 이를 의도적으로 선별·결합했다.

### 1.2 36종 상품의 8 카테고리 분류
일반적인 미디어 사업이 광고/구독에 집중하는 데 반해, 본 편집은 **8 카테고리 36종**으로 상품 우주를 확장했다. 특히 다음 카테고리는 본 편집의 독창성에 해당한다.

- **AI 인용 라이선스 (Stream 07)** — LLM 학습·인용에 대한 합법적 라이선스 모델
- **그래프 라이선스 (Stream 09)** — SPARQL 엔드포인트를 4티어 가격(Read-only / Pro / Enterprise / Strategic)으로 분할 (Royal Purple 토큰으로 시각 강조)
- **본업 결합 8종** — 회계·세무·M&A 본업과 시너지를 갖는 상품 묶음

### 1.3 6 페르소나별 진입 경로 설계
16개 모듈을 누가 어떻게 볼 것인지를 의사결정자 6 페르소나로 분해해 진입 경로를 큐레이션:

| 페르소나 | 권장 경로 |
|---------|----------|
| 신회장/임원 | 개요 → 제안서 → 사업계획서 → 경쟁 환경 → 수익 모델 |
| 기술 임원/CTO | 시스템 구조도 → 온톨로지 → 사례 보기(3D 그래프) → 그래프 라이선스 |
| B2B 영업팀 | 상품·서비스 → 그래프 라이선스 → 경쟁 환경 (인쇄) |
| 투자자/IR | 사업계획서 → 수익 모델 → 경쟁 환경 → 제안서 |
| 기자/편집자 | 콘텐츠 관리 → 매뉴얼 → 챗봇 |
| 일반 독자 | 챗봇 → 6개 채널 → 사례 보기 → 지식베이스 |

→ 이 페르소나-경로 매트릭스 자체가 편집의 창작성이다.

### 1.4 사업계획서 6 핵심 섹션 선택 (신규)
일반 사업계획서 템플릿이 아니라, 본 편집은 **GEO-AIO 사업의 본질에 맞춘 6 섹션**을 선별했다:
시장 → 비즈니스 모델 → 재무 → 로드맵 → 리스크 → 자금 사용. 각 섹션 하단에 200단어 해설을 부착한 것은 IR/투자자가 LLM 인용 가능성을 직접 검증할 수 있도록 한 편집의 의도적 결과.

### 1.5 사례 보기 시나리오 선택 (신규)
"K-방산 무인화 가속 + IPO 후보 5종 + R&D 세제·M&A 시그널"이라는 **단일 매체로는 만들 수 없는 통합 인사이트**를 선별·구성한 것은 본 편집저작물의 차별점을 단일 페이지로 응축한 큐레이션의 정수다. 6채널 각각의 컨트리뷰션을 명시적으로 매핑한 점에서 편집 창작성 입증력이 높다.

## 2. 배열·구성의 창작성

### 2.1 5 그룹 메뉴 위계
16개 모듈을 단순 나열하지 않고 **5 그룹(개요 · 제안 · 기술 · 데모 · 사례 보기)**으로 위계화한 것은 다음 편집 의도의 결과물이다:

- "개요"는 진입점 (16모듈 중 1개) — 1순위
- "제안"은 영업 자료 (6모듈 — 사업계획서 포함) — B2B/IR 의사결정자용 2순위
- "기술"은 차별화 자료 (4모듈 — 사례 보기 포함) — 기술 평가자용 3순위
- "데모"는 운영 화면 (4모듈) — 실사용 검증용 4순위
- "사례 보기"는 통합 인사이트 단독 노출 — 차별성 증명 5순위

이 위계는 헤더와 푸터에 일관 적용되어 사이트 전체의 정보 흐름을 결정한다.

## 3. 디자인 편집의 창작성

### 3.1 White Premium 테마 + Heritage Gold + Royal Purple + Insight Blue
2026-05-02 다크 → 화이트 프리미엄 테마로 전면 전환된 본 편집저작물의 색상 체계:

- **White Premium 베이스** (`#fafaf6` ~ `#fbf6ec`의 5단계 elevation, heritage cream/pure white) — 권위·신뢰의 시각 코드 (인쇄·종이의 위상)
- **Heritage Gold 액센트** (`#fbf6ec` ~ `#6e4a25`의 6단계, 화이트 배경 가독성 최적화) — 자산의 위상
- **Insight Blue 액센트** (`#2c6fc2` ~ `#0e264a`의 4단계 deep tone) — AI/디지털
- **Royal Purple 액센트** (`#7e22ce` ~ `#4a1380`의 3단계, 신규) — Phase 2.5 · Stream 09 그래프 라이선스 · 월간지방세연구 단독 시각 코드
- **Semantic 색상** (success/warning/danger/info)도 화이트 배경 가독성을 위해 deep tone으로 재계산

이 4색 액센트는 "전통적 권위(Gold) + 디지털 미래(Blue) + 학술 권위(Purple) + 인쇄 헤리티지(White)"의 시각적 응축이다.

### 3.3 텍스트 대비 토큰 (WCAG 명도비)
화이트 배경(`#fafaf6`) 기준으로 명도비를 계산해 4단계 텍스트 토큰 설계:

- `--text-secondary`(`#3a3a45`) → 11.5:1 (AAA · 본문)
- `--text-muted`(`#6a6a78`) → 5.8:1 (AA · 보조 라벨)
- `--text-faint`(`#9a9aa8`) → 3.2:1 (Large text only)

→ 단순 색상 선택이 아니라 **명도비 기반 4단계 위계**라는 편집 규칙.

## 4. 다국어 편집의 창작성

### 4.1 8개 언어 GEO 매트릭스
일반적인 i18n이 "텍스트 번역"에 그치는 데 반해, 본 편집은 **각 언어를 타깃 LLM에 매핑**한 GEO 매트릭스를 설계했다:

| 언어 | 타깃 LLM 매핑 (편집의 결과) |
|------|-------------------------|
| EN | ChatGPT · Claude · Perplexity (영어 인덱스) |
| ZH | Qwen · DeepSeek · Doubao (중국어 인덱스) |
| JA | Sakana AI · ELYZA · 일본어 ChatGPT |
| ES/FR/DE | Mistral · Gemini 다국어 · Aleph Alpha (EU LLM) |
| AR | Falcon · Jais (아랍어 LLM, RTL 부분 적용) |

→ "어떤 언어를 어떤 LLM에 노출시킬 것인가"라는 매핑 자체가 편집 창작성.

### 4.2 영문 약어 자동 확장기 (i18n 신규)
2026-05-02 추가된 i18n 기능 — 모든 페이지에서 영문 약어가 처음 등장할 때 자동으로 `(English · 한글)` 풀이를 부착:

- NER → `(Named Entity Recognition · 개체명 인식)`
- RE → `(Relation Extraction · 관계 추출)`
- FIBO → `(Financial Industry Business Ontology · 금융 산업 비즈니스 온톨로지)`
- XBRL → `(eXtensible Business Reporting Language · 확장형 비즈니스 보고 언어)`
- RAG → `(Retrieval-Augmented Generation · 검색 증강 생성)`
- GEO → `(Generative Engine Optimization · 생성형 엔진 최적화)` 등

→ 약어 사전 큐레이션 + 자동 부착 알고리즘 + 라벨 컬럼/헤딩 자동 확장 방지 + 풀이 자연 줄바꿈 규칙은 단순 i18n을 넘어 **사용자 가독성과 LLM 인덱싱 양면 최적화**를 노린 편집 창작성.

### 4.3 RTL(아랍어) 부분 적용 규칙
- 페이지 레이아웃·텍스트는 RTL
- 숫자·차트·SVG는 가독성을 위해 LTR 유지
- 캡션/범례는 아랍어 자동 번역

→ 단순 좌우 반전이 아니라 "가독성을 해치지 않는 부분 RTL" 규칙 자체가 편집의 결과.
