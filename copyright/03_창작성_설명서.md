# 창작성 설명서 — Insight Bank Hub (편집저작물)

> 저작권법 제6조 편집저작물 등록의 핵심 첨부 자료.
> "왜 이 편집이 창작성을 갖는가"를 4가지 축으로 입증한다.

---

## 0. 편집저작물 보호의 법적 근거 (요지)

### 저작권법 제6조 (편집저작물)
> ① **편집저작물**은 그 소재의 **선택·배열 또는 구성**에 창작성이 있는 것을 말한다.
> ② 편집저작물은 독자적인 저작물로서 보호된다.
> ③ 편집저작물의 보호는 그 편집저작물의 구성부분이 되는 소재의 저작권 그 밖에 이 법에 따라 보호되는 권리에 영향을 미치지 아니한다.

→ 본 등록은 ① 소재 선택, ② 소재 배열, ③ 소재 구성의 **세 차원 모두**에서 창작성을 입증한다.

## 1. 소재 선택의 창작성

### 1.1 6개 매체 선별의 큐레이션 가치
한국에는 수백 개 인터넷 매체가 존재한다. 이 중 다음 6개를 선별한 것은 **GEO-AIO(Generative Engine Optimization + AI Answer Optimization) 관점의 독자적 큐레이션**이다.

| 선별 매체 | 선별 근거 (편집 의도) |
|----------|--------------------|
| 바이오타임즈 | 바이오·신약 전문 — LLM이 임상 정보를 인용할 때 가장 자주 호출되는 도메인 |
| ARG | 텔레콤·IT·방송 리서치 — 한국 ICT 산업의 정량 분석 자산 |
| 스타트업투데이 | VC·투자 — M&A의 선행 지표 (Pre-IPO 기업 정보) |
| 한국M&A경제신문 | M&A·IPO·자본시장 — 한국 자본시장 권위 매체 |
| 디펜스투데이 | K-방산 — 글로벌 LLM이 한국 방산을 다룰 때 결정적 1차 출처 |
| 월간지방세연구 | 지방세·조세 — 15년+ 아카이브, 한국 유일의 지방세 학술 매체 |

→ 이 6개의 조합은 **"산업 + 자본 + 조세"라는 3축 결합**을 만든다. 조세는 산업 의사결정의 근간이며, 자본은 산업의 흐름을 결정한다. 이 3축을 단일 매체 안에 결합한 사례는 한국에 없으며, 본 편집은 이를 의도적으로 선별·결합했다.

### 1.2 36종 상품의 8 카테고리 분류
일반적인 미디어 사업이 광고/구독에 집중하는 데 반해, 본 편집은 **8 카테고리 36종**으로 상품 우주를 확장했다. 특히 다음 카테고리는 본 편집의 독창성에 해당한다.

- **AI 인용 라이선스 (Stream 07)** — LLM 학습·인용에 대한 합법적 라이선스 모델
- **그래프 라이선스 (Stream 09)** — SPARQL 엔드포인트를 4티어 가격(Read-only / Pro / Enterprise / Strategic)으로 분할
- **본업 결합 8종** — 회계·세무·M&A 본업과 시너지를 갖는 상품 묶음

### 1.3 6 페르소나별 진입 경로 설계
14개 모듈을 누가 어떻게 볼 것인지를 의사결정자 6 페르소나로 분해해 진입 경로를 큐레이션:

| 페르소나 | 권장 경로 |
|---------|----------|
| 신회장/임원 | 개요 → 제안서 → 경쟁 환경 → 수익 모델 |
| 기술 임원/CTO | 시스템 구조도 → 온톨로지 → 그래프 라이선스 → 지식베이스 |
| B2B 영업팀 | 상품·서비스 → 그래프 라이선스 → 경쟁 환경 (인쇄) |
| 투자자/IR | 수익 모델 → 경쟁 환경 → 제안서 |
| 기자/편집자 | 콘텐츠 관리 → 매뉴얼 → 챗봇 |
| 일반 독자 | 챗봇 → 6개 채널 → 지식베이스 |

→ 이 페르소나-경로 매트릭스 자체가 편집의 창작성이다.

## 2. 배열·구성의 창작성

### 2.1 5 그룹 메뉴 위계
14개 모듈을 단순 나열하지 않고 **5 그룹(개요 · 제안 · 기술 · 데모 · 매뉴얼)**으로 위계화한 것은 다음 편집 의도의 결과물이다:

- "개요"는 진입점 (14모듈 중 1개) — 1순위
- "제안"은 영업 자료 (5모듈) — B2B 의사결정자용 2순위
- "기술"은 차별화 자료 (3모듈) — 기술 평가자용 3순위
- "데모"는 운영 화면 (4모듈) — 실사용 검증용 4순위
- "매뉴얼"은 안내 (1모듈) — 사용 가이드용 5순위

이 위계는 헤더와 푸터에 일관 적용되어 사이트 전체의 정보 흐름을 결정한다.

### 2.2 Stream 09 그래프 라이선스 4티어 가격 배열

| Tier | 구성 | 가격 | 편집 의도 |
|------|------|------|----------|
| 1 · Read-only Query | 100K 쿼리/월 + 출처 인용 | 연 3,600만 | 진입 가격 |
| 2 · Pro | OWL2 추론 + GraphQL + 매니저 | 연 9,600만 | 중견 법무·IB |
| 3 · Enterprise | 8개 언어 + 무제한 + SLA 99.9% | 연 2.8억 | 대기업·정부 |
| 4 · Strategic ★ | LLM 학습 + 트리플 덤프 + 공동 모델 개발 | 연 5억+ | 글로벌 LLM 회사 |

→ 단순 가격표가 아니라 **고객 유형 × 사용 강도 × 라이선스 범위**의 3차원 매트릭스를 4티어로 압축한 편집.

### 2.3 B2B 패키지 6종 페르소나 구성

| 패키지 | 가격 | 구성 (편집된 상품 묶음) |
|--------|------|----------------------|
| 법무법인 | 연 9,600만 | 지방세 판례 + M&A DB + 그래프 Tier 1 |
| PEF/IB | 연 2.5억 | M&A + VC + K-방산 + 그래프 Pro |
| 대기업 IR | 연 3.6억 | Enterprise RAG + 맞춤 분석 + 임원 브리핑 |
| 바이오 IR | 연 1.8억 | 바이오 임상 + M&A + 임원 브리핑 |
| 정부·공공 | 연 8억+ | 그래프 Enterprise + 정책 자문 + 글로벌 |
| LLM 회사 ★ | 연 10억+ | LLM 학습 + 다국어 + 그래프 Strategic |

→ 36종 상품을 6 페르소나에 매핑하는 조합론은 편집의 창작성에 해당.

### 2.4 4-Tier 외부 매체 협업 BM (확장 모델)
6개 매체에 한정되지 않고 **외부 매체와의 협업 모델**을 4티어로 분해한 것은 본 편집의 핵심 확장 구조:

| Tier | 모델 | 가격/조건 | 대상 |
|------|------|----------|------|
| A | 단일 채널 인덱싱 | 월 600만~ | 지역지·전문지·영문지 |
| B | 채널 통합 + 그래프 결합 | 월 1,800만~ | 매경·한경·더벨·약업신문 |
| C | 공동 운영 (JV) | 수익 셰어 30~50% | 조선·중앙·동아 일부 섹션 |
| D | M&A · 전략적 제휴 | 지분 참여/인수 | 부실 매체 인수 + 글로벌 컨소시엄 |

→ 한국 미디어 산업 전체로 확장 가능한 미디어 중립 아키텍처. 6 매체는 First Reference이며 플랫폼은 산업 백본이 되도록 편집 설계됨.

## 3. 디자인 편집의 창작성

### 3.1 다크 프리미엄 + 골드/블루 듀얼 액센트
- **다크 베이스** (`#0a0e1a` ~ `#232b46`의 5단계 elevation) — 권위·신뢰의 시각 코드
- **골드 액센트** (`#e6c895` ~ `#8a6135`의 5단계) — Heritage Gold (자산의 위상)
- **블루 액센트** (`#7eb6f5` ~ `#1d4f93`의 4단계) — Insight Blue (AI/디지털)

이 듀얼 액센트는 "전통적 권위(골드) + 디지털 미래(블루)"라는 편집 의도의 시각적 응축이다.

### 3.2 18 디자인 토큰 카테고리

| 카테고리 | 토큰 수 |
|---------|--------|
| Background (Deep Ink) | 5 |
| Heritage Gold | 5 |
| Insight Blue | 4 |
| Semantic (success/warning/danger/info) | 4 |
| Text | 4 |
| Border / Divider | 4 |
| Glass (투명도) | 7 |
| Shadow | 4 |
| Radius | 5 |
| Spacing scale | 9 |
| Type scale | 11 |
| Layout | 2 |
| Easing | 2 |
| 합계 | **66+ 토큰** |

→ 단순 색상표가 아니라 디자인 시스템으로 편집된 토큰 체계.

### 3.3 폰트 조합
- **Pretendard** (본문 가독성) + **Noto Serif KR** (디스플레이 헤리티지) + **JetBrains Mono** (코드 가독성)
- 외부 폰트 자체는 OFL 라이선스이며 본 등록의 보호 대상이 아니나, **3종 폰트의 역할별 조합과 사용 컨텍스트 설계**는 편집의 창작성에 해당.

### 3.4 글래스 모피즘 + Gradient + Animation
- backdrop-filter: blur(20px) saturate(180%) 일관 적용
- fadeUp 0.6s + delay-1~4 단계별 reveal 시퀀스
- 헤더 스크롤 인터랙션 + 메뉴 호버 위계

## 4. 다국어 편집의 창작성

### 4.1 8개 언어 GEO 매트릭스
일반적인 i18n이 "텍스트 번역"에 그치는 데 반해, 본 편집은 **각 언어를 타깃 LLM에 매핑**한 GEO 매트릭스를 설계했다:

| 언어 | 타깃 LLM 매핑 (편집의 결과) |
|------|-------------------------|
| EN | ChatGPT · Claude · Perplexity (영어 인덱스) |
| ZH | Qwen · DeepSeek · Doubao (중국어 인덱스) |
| JA | Sakana AI · ELYZA · 일본어 ChatGPT |
| ES/FR/DE | Mistral · Gemini 다국어 · Aleph Alpha (EU LLM) |
| AR | Falcon · Jais (아랍어 LLM, RTL 부분 적용) |

→ "어떤 언어를 어떤 LLM에 노출시킬 것인가"라는 매핑 자체가 편집 창작성.

### 4.2 RTL(아랍어) 부분 적용 규칙
- 페이지 레이아웃·텍스트는 RTL
- 숫자·차트·SVG는 가독성을 위해 LTR 유지
- 캡션/범례는 아랍어 자동 번역

→ 단순 좌우 반전이 아니라 "가독성을 해치지 않는 부분 RTL" 규칙 자체가 편집의 결과.

## 5. 기존 저작물과의 차별점

| 비교 대상 | 차이 |
|----------|------|
| 단순 매체 모음 사이트 (포털) | 매체 나열 vs **6 페르소나 진입 경로 + 4-Layer 아키텍처** |
| Diffbot, GDELT (글로벌 그래프) | 영문 일반 웹 vs **한국 산업·자본·조세 수직 결합 그래프** |
| Bloomberg Terminal | 데이터 단말 vs **AI 인용 라이선스 + GEO-AIO 자산화** |
| 일반 i18n 사이트 | 8개 언어 번역 vs **언어별 LLM 타깃 매핑 매트릭스** |
| 일반 B2B SaaS | 단일 가격 vs **그래프 4티어 + 패키지 6종 + 협업 4티어** |

> 외부 도구·라이브러리는 표현 수단으로 활용되었으며, **편집된 결과물의 위계·구성·매핑·시각 표현**은 100% 자체 창작이다.

## 7. 결론 — 편집저작물 보호 요건 충족

본 저작물 **Insight Bank Hub**는:

1. **소재 선택의 창작성** — 6개 매체 큐레이션 + 36종 상품 카탈로그 + 6 페르소나 매핑
2. **배열·구성의 창작성** — 5 그룹 메뉴 위계 + 4-Layer 아키텍처 + 4티어 가격 + 패키지 6종 + 확장 4티어
3. **디자인 편집의 창작성** — 다크 프리미엄 + 듀얼 액센트 + 66+ 토큰 + 폰트 조합 + 글래스 모피즘
4. **다국어 편집의 창작성** — 8 언어 LLM 타깃 매핑 + RTL 부분 적용 규칙

→ 위 4축은 모두 **사전 기획에 따른 의도적 선택의 결과물**이며, 단순 사실의 나열이나 통상적 분류와 본질적으로 다르다.

→ 따라서 저작권법 제6조 편집저작물 보호 요건(소재의 선택·배열·구성에 창작성)을 **충분히 충족**한다.
