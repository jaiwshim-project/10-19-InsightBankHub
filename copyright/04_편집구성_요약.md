# 편집 구성 요약 — Insight Bank Hub (편집저작물)

> 한국저작권위원회 편집저작물 등록 시 첨부하는 **편집의 결과물 발췌 자료**.
> 본 등록은 **소스코드의 창작성이 아니라 편집(소재 선택·배열·구성)의 창작성**을 보호 대상으로 한다.
> 본 자료는 따라서 코드 발췌가 아닌 **편집된 결과물**(메뉴 위계·카탈로그·매핑 표·디자인 토큰 매핑·약어 사전 등)을 발췌한다.
> 50페이지 이내 분량으로 위원회 제출용으로 정리.

## 1. 편집 발췌 1 — 5 그룹 메뉴 위계 (배열 의사결정의 결과)

```
헤더 메뉴 (저작자가 결정한 정보 위계)
┌─ 개요                              ← 진입점 1순위
├─ 제안 · 영업 (드롭다운, 6 모듈)     ← B2B/IR 의사결정자용 2순위
│   계약 제안서 · 6개 채널 · 상품·서비스
│   수익 모델 · 경쟁 환경 · 사업계획서
├─ 기술 · 차별화 (드롭다운, 4 모듈)   ← 기술 평가자용 3순위
│   시스템 구조도 · 온톨로지
│   그래프 라이선스 · 사례 보기
├─ 플랫폼 · 데모 (드롭다운, 4 모듈)   ← 실사용 검증용 4순위
│   대시보드 · 콘텐츠 관리
│   지식베이스 · RAG 챗봇
└─ 사례 보기                         ← 차별성 증명 5순위
```

> ※ 14개 모듈을 5 그룹으로 위계화한 결정(커밋 `770f6c2`)은 저작자의 단독 편집 의사결정.

## 2. 편집 발췌 2 — 6 페르소나별 진입 경로 매트릭스

| 페르소나 | 권장 경로 (저작자 큐레이션) |
|---------|---------------------------|
| 신회장/임원 | 개요 → 제안서 → 사업계획서 → 경쟁 환경 → 수익 모델 |
| 기술 임원/CTO | 시스템 구조도 → 온톨로지 → 사례 보기(3D 그래프) → 그래프 라이선스 |
| B2B 영업팀 | 상품·서비스 → 그래프 라이선스 → 경쟁 환경 (인쇄) |
| 투자자/IR | 사업계획서 → 수익 모델 → 경쟁 환경 → 제안서 |
| 기자/편집자 | 콘텐츠 관리 → 매뉴얼 → 챗봇 |
| 일반 독자 | 챗봇 → 6개 채널 → 사례 보기 → 지식베이스 |

> ※ 페르소나×경로 매핑은 일반적인 사이트맵에 없는 **저작자 의사결정의 결과**.

| Stream | 비고 |

### 4.2 Stream 09 — 4-Tier 가격 배열

| Tier | 구성 | 가격 |
|------|------|------|
| 1 · Read-only Query | 100K 쿼리/월 + 출처 인용 | 연 3,600만 |
| 2 · Pro | OWL2 추론 + GraphQL + 매니저 | 연 9,600만 |
| 3 · Enterprise | 8개 언어 + 무제한 + SLA 99.9% | 연 2.8억 |
| 4 · Strategic ★ | LLM 학습 + 트리플 덤프 + 공동 모델 개발 | 연 5억+ |

→ **고객 유형 × 사용 강도 × 라이선스 범위**의 3차원 매트릭스를 4티어로 압축한 편집.
