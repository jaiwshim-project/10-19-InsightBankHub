03 · 창작성 입증

4축 창작성 — 왜 이 편집이 보호되는가

① 소재 선택의 창작성

  • 한국 수백 매체 중 산업+자본+조세 3축을 만드는 6개 매체 선별
  • 36종 상품을 8 카테고리로 의미 분류 (AI 인용 라이선스 · 그래프 라이선스 신설)
  • 의사결정자 6 페르소나별 진입 경로 매트릭스
  • 사업계획서: GEO-AIO 사업 본질에 맞춘 6 섹션 선택
  • 사례 보기: 단일 매체 흉내 불가한 통합 시나리오 큐레이션

② 배열·구성의 창작성

  • 16 모듈을 5 그룹 메뉴 위계로 재구성 (헤더·푸터 일관)
  • 4-Layer 아키텍처 + 3D 온톨로지 그래프 시각화
  • 그래프 4티어 가격(Read-only/Pro/Enterprise/Strategic) 매트릭스
  • B2B 패키지 6종 — 36종 상품의 페르소나별 매핑
  • 사례 보기 — 단일 시나리오에 6채널 컨트리뷰션 분담 매핑

③ 디자인 편집의 창작성

  • White Premium 베이스 + Heritage Gold + Royal Purple + Insight Blue 4색 체계
  • 74+ 디자인 토큰 (5단계 elevation · 9단계 spacing · 11단계 type scale)
  • KoPubWorld Dotum (한국출판인회의) — 로컬+CDN 3순위 폴백
  • WCAG 명도비 4단계 텍스트 토큰 (16:1 ~ 3.2:1)
  • 글래스 모피즘 + fadeUp 시퀀스 + 스크롤 인터랙션

④ 다국어 편집의 창작성

  • 8 언어 → 타깃 LLM 매핑 매트릭스 (EN→ChatGPT, ZH→Qwen ...)
  • 영문 약어 자동 확장기 — 첫 등장 시 (English · 한글) 풀이
  • 약어 사전 큐레이션 (NER · RE · FIBO · XBRL · RAG · GEO 등)
  • RTL(아랍어) 부분 적용 규칙 — 가독성을 위해 숫자·차트는 LTR 유지
  • 도메인 전문 용어 한국어 표준화 + LLM 인덱싱 양면 최적화

06 · 등록 방법

한국저작권위원회 등록 절차

  1. cros.or.kr 접속 및 회원가입 한국저작권위원회 저작권 등록 시스템(cros.or.kr)에 접속하여 실명 인증 후 회원가입.
  2. 저작권 등록 → 편집저작물 등록 신청 메뉴에서 편집저작물 등록 신청서를 선택. 본 페이지의 등록 개요(섹션 01)와 등록 자료 01번을 그대로 입력.
  3. 첨부 파일 업로드 02 명세서 + 03 창작성 설명서(핵심) + 04 소스코드 요약 + 05 구조도 + 07 Git 이력 + 신분증 사본을 업로드. 06 스크린샷은 권장.
  4. 수수료 결제 — 26,800원 편집저작물 1건 등록 수수료. 신용카드 또는 가상계좌.
  5. 처리 대기 — 7~14일 위원회 심사 후 등록증 발급. 보정 요청 시 추가 7~14일 소요.
  6. 등록 완료 후 효력 분쟁 시 창작 시점·저작자·소유권의 추정 근거(저작권법 제53조). 등록 후 위반에 대한 법정손해배상 청구 가능(제125조의2).
편집저작물 보호 범위
본 등록은 소재(원저작물)의 선택·배열·구성에 대한 창작성에 한해 보호됩니다. 편집된 개별 소재 — 6개 매체의 콘텐츠, 외부 폰트(KoPubWorld Dotum · Pretendard · Noto Serif KR), 외부 라이브러리(3D-Force-Graph 등) — 는 별도 권리자에게 권리가 있으며 본 등록의 보호 범위가 아닙니다.
